02 · 置入原因

为什么新模型可能让这批人进来

从画像差异反推的四个可能驱动，不等于模型真实决策逻辑。

数据中没有新模型的评分、特征重要度或拒绝原因，无法直接还原决策逻辑。下面只能从置入组相对置出组的稳定差异，反推四个可能原因；它们是画像假设，不是模型事实。

1. 非工资/多源收入被识别

多源/非工资收入 置入 61.0% / 置出 27.3%；工资占比 置入 21.7% / 置出 42.1%；无工资入账 置入 19.0% / 置出 0.7%。模型可能更依赖交易流水识别收入，而不是工资标签。

2. 历史负债更轻

有放款 置入 72.7% / 置出 88.5%；放款笔数中位 置入 4 / 置出 8；放款金额中位 置入 A$1,050 / 置出 A$2,780；现金贷/工资贷 置入 49.8% / 置出 69.1%；高负债 置入 19.2% / 置出 32.4%。

3. 拒付更轻

未结清拒付 置入 52.0% / 置出 59.0%；未结清笔数中位 置入 1 / 置出 2；金额中位 置入 A$53 / 置出 A$278。整体比例区间有重叠，但笔数和金额方向一致。

4. 用薄缓冲换低负债

支出≥收入 置入 49.0% / 置出 37.4%；低缓冲标签 置入 25.1% / 置出 17.3%；负现金流 置入 55.5% / 置出 51.1%。这更像一次主动取舍：用更弱的工资可见性和更薄的缓冲，换更低的负债/拒付。

排除几个直观但证据不足的解释：收入规模接近（A$82.1k / A$79.2k），不足以解释置换；交易活跃度也不更高（活跃天数中位 125 / 131）；健康分也不是更高（53.2 / 55.3）。最可能的解释是：新模型把负债/拒付强度放在工资稳定性之前，用“低负债 + 多源流水”换“工资可见性”。

04 · 置出原因

为什么新模型可能把这批人换出

从画像差异反推的可能原因，以及不能排除的替代解释。

如果只看现金流，置出组并不比置入组差；真正拉开差距的是借贷与拒付。以下同样是画像反推，不是模型事实。

1. 历史借贷更重

有放款 置入 72.7% / 置出 88.5%；放款笔数中位 置入 4 / 置出 8；金额中位 置入 A$1,050 / 置出 A$2,780；现金贷/工资贷 置入 49.8% / 置出 69.1%；高负债 置入 19.2% / 置出 32.4%。

2. 拒付恢复更差

未结清 置入 52.0% / 置出 59.0%；未结清笔数中位 置入 1 / 置出 2；金额中位 置入 A$53 / 置出 A$278；部分解决 置入 19.3% / 置出 33.1%。整体比例区间有重叠，但笔数、金额和恢复状态方向一致。

3. 高风险分群更集中

高风险承压 置入 45.4% / 置出 53.2%（风险标签≥3）。但三项压力交集置出组反而更低（置入 12.9% / 置出 9.4%），说明模型不是简单按复合标签排序。

4. 工资稳定没有抵消上述信号

收入稳定性得分 置入 50.9 / 置出 60.7；健康分中位数 置入 53.2 / 置出 55.3。置出组靠收入维度把总分拉高；如果按现有健康分排序，置出组反而更高，新模型可能用了不同权重或额外否决项。

最可能的解释：新模型把“历史借贷强度 + 拒付恢复”当成更强的否决项；工资稳定、现金流尚可，但不足以抵消这两项。另一个不能排除的解释是策略/政策规则而非纯模型分数——仅凭画像无法区分。

需要验证低负债/低拒付能否抵消薄缓冲带来的逾期风险；重点跟踪 Swap In 的现金流断裂与小额拒付滚动。

如果目标是扩大覆盖

置入组确实覆盖了传统工资模型不容易识别的非工资/多源收入人群；价值在覆盖，而不是风险更低。

07 · 结论与边界

结论：置入了谁，为什么；置出了谁，为什么

一页总结，以及需要后续验证的边界。

一句话总结：新模型置入的是“负债更轻、工资更不可见、现金流更紧”的人；置出的是“工资更稳定、但借贷与拒付更重”的人。

置入侧 · 为什么可能进

多源/非工资 61.0%；负债轻（放款 72.7%、现金贷 49.8%）；拒付轻（52.0%）；代价是现金流薄（支出≥收入 49.0%、低缓冲 25.1%）。

置出侧 · 为什么可能出

工资更稳定（工资占比 42.1%）；但借贷重（放款 88.5%、8 笔、A$2,780）；拒付重（59.0%、2 笔、A$278）。

验证模型原因

两版入模变量已核对：新模型更偏近期余额/转账/负债行为；下一步拉取模型评分、SHAP/特征重要度与拒绝原因码，核对方向与强度。

验证置换效果

等 duedate_1m_5 等表现标签成熟，比较 Swap In / Swap Out 的逾期与还款；当前标签仅 83/641 与 31/139 有值，阳性 11/5，不能做结果对比。

验证策略属性

确认置出是否包含政策、名单或人工规则；仅凭画像无法区分“模型分数”与“策略规则”。

结论适用边界：（1）两组按置换结果划分，不是随机实验，差异不能归因于置换动作本身；（2）Swap Out 仅 139 条，拒付、流动性、近期缺口等指标区间重叠；（3）健康分是合并样本内的相对分数，不等同于违约概率；（4）画像差异只能支持“可能原因”，不能证明模型真实决策逻辑。
数据来源与口径

输入：existing_swap_in_v1_2_with_feature_all.csv、existing_swap_out_v1_2_with_feature_all.csv；合并后 780 条申请。输出：analysis/swap_compare/out/。评分沿用 products/fundo.json 的 122 个注册指标与 46 个计分指标，断点由合并样本统一计算。
